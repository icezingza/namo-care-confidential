## Email Sending Workflow

1. **Personalize:** Use actual contact name + company details (not generic template)
2. **A/B test subject lines:**
   - Version A: "Production-Ready Elderly Care Platform (Medical-Grade, PDPA-Compliant)"
   - Version B: "Save 6 Months on Elderly Care Development"
   - Version C: "฿4.1B TAM Opportunity: Medical-Grade Elderly Care Platform"
3. **Track opens/clicks:** Use email tracking tool (e.g., Streak, HubSpot, Mailchimp)
4. **Follow-up cadence:**
   - Day 0: Send email
   - Day 3: Follow-up if no open (resend with slightly different subject)
   - Day 8: Phone call or LinkedIn message if email opened but no reply
   - Day 15: Move to next prospect list or mark as "revisit in 3 months"
